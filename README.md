## О проекте

Данный репозиторий содержит материалы курсовой работы на тему **«Разработка системы прогнозирования оттока клиентов для телеком-компании»**. Проект посвящен решению одной из ключевых бизнес-задач в телекоммуникационной отрасли — прогнозированию оттока клиентов (churn prediction).

**Цель работы** — разработать и реализовать модель машинного обучения, способную с высокой точностью выявлять клиентов, склонных к уходу от оператора.

## Основные задачи

1.  **Анализ предметной области**: Изучение причин и факторов, влияющих на отток клиентов в телекоммуникациях.
2.  **Сбор и подготовка данных**: Загрузка, очистка, анализ и предобработка датасета `Telco Customer Churn`.
3.  **Исследовательский анализ данных (EDA)**: Выявление закономерностей и зависимостей в данных, анализ распределений и корреляций.
4.  **Построение и обучение моделей**: Реализация и обучение широкого спектра моделей машинного обучения.
5.  **Оценка и выбор модели**: Сравнение эффективности моделей на основе метрик (Accuracy, Recall, Precision, F1-score, ROC-AUC, Cohen's Kappa) и выбор оптимального алгоритма.
6.  **Настройка гиперпараметров**: Оптимизация параметров лучших моделей с помощью `GridSearchCV` для повышения их производительности.

## Данные

Проект использует датасет **Telco Customer Churn**, доступный на платформе Hugging Face.

*   **Источник**: `https://huggingface.co/datasets/aaib510-group1/telco-customer-churn`
*   **Файлы**: Данные разделены на `train.csv` (обучающая выборка) и `test.csv` (тестовая выборка).
*   **Признаки**: Датасет содержит информацию о демографии клиентов, используемых услугах, типах контрактов, платежах и финансовых показателях.
*   **Целевая переменная**: `Churn` (0 — клиент остался, 1 — клиент ушел).

### Ключевые этапы обработки данных:
*   **Очистка**: Удаление неинформативных и дублирующихся признаков (например, 'Customer ID', 'Lat Long', 'Churn Reason').
*   **Устранение мультиколлинеарности**: Анализ корреляционной матрицы и удаление сильно скоррелированных признаков.
*   **Кодирование категориальных признаков**: Применение бинарного кодирования (`Gender`) и One-Hot Encoding (`Contract`, `Payment Method`).
*   **Нормализация**: Масштабирование числовых признаков с помощью `StandardScaler`.

## Результаты

В ходе работы были протестированы и сравнены различные модели машинного обучения, включая логистическую регрессию, SVM, деревья решений, ансамблевые методы (Random Forest, Gradient Boosting, LGBM, XGBoost) и нейронные сети.

**По результатам сравнения и настройки гиперпараметров наилучшей была признана модель `LGBM Classifier`**, которая показала лучший баланс между основными метриками (наибольшее значение F1-меры) при прогнозировании оттока.

### Метрики оптимальной модели (LGBM Classifier) на тестовом наборе:

| Метрика | Значение |
| :--- | :--- |
| **Accuracy** | 0.8581 |
| **Recall** | 0.6845 |
| **Precision** | 0.7574 |
| **F1-score** | 0.7191 |
| **ROC-AUC** | 0.8026 |
